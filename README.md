# Smart Vehicle Black Box

An ESP32-based vehicle safety system designed for accident, speed and pothole detection.

## Components

ESP32 | MPU6050 | GPS | GSM | Micro SD | RTC | Buzzer | LED

## Features

- Accident detection
- Speed and pothole monitoring
- GPS location tracking
- GSM communication
- Data logging using Micro SD
- Buzzer and LED alerts
